# Story — Tone / Opening / Body-Swap / Prestige

**言語:** 中／英／日混寫。日本語は概念ラベル用。  
**Tone:** cozy in a wasteland；風味文字帶幽默；**極少對話**，訊息主要靠 description／flavour text。  
**No code yet.**

---

## 1. Premise（前提）

玩家是 **Saikoro（骰子）**，在廢土世界經營一列火車：跑商、擴建、偶爾收徒當 courier。世界硬、日子卻可以過得溫吞好笑。

敘事主軸不是長篇對話，而是：

- 地點／商品／任務的短描述
- 開場與結局的幾個關鍵 beat
- 威望重開後慢慢拼回來的「名字／外觀碎片」

---

## 2. Opening flow（開場流程）

1. **選名字**（預設可叫 Saikoro，可改）。
2. **選外觀（body）** — 玩家以為這就是自己。
3. 系統／神祇以閒淡語氣給玩家一面 **鏡（mirror）**。
4. 照鏡：**外表已經和剛選的不一樣**（swap 已發生，但尚未說明「是神換的」）。
5. 進入遊戲：一列破車、第一站、教學向的低利運送委託與買賣。
6. **開場即暗示**玩家與神「賽子／Dice」有關（諧音／稱謂／鏡子旁白），但不說破換身真相。

> 鏡子 = 早期異常訊號；完整真相留到最後。

### 2.1 Flavour direction（開場風味）

- 不要嚇嚇叫的恐怖文；偏「嗯？鏡子有點毛病」的乾幽默。
- UI 可把鏡子當一次性道具／開場插圖，不必長 cutscene。

---

## 3. Mid-game story texture（中段）

- **幾乎無對話。** NPC（含 Zone1 拜師 courier）用短 description／任務說明即可。
- Zone1 courier 支線：當地人想學跑商 → 成為鎖在 Zone1 的信使（見 systems）。
- 約 Zone3：universal courier 支線（見 systems）——敘事上可以是「路網夠大、神／世界允許第二雙手」。
- 鏡子相關的風味文字可偶發（車站塗鴉、廢品說明），**不劇透神換身**。

---

## 4. Late reveal（最後揭示）

在 **很晚、接近地圖終點** 揭曉（精確站點／任務 TBD）：

- 開場選的 **body 被神拿走／換走**。
- 玩家從頭到尾開的是「被留下的那具／被改過的那具」——與鏡子異樣對上。
- 語氣仍保持 cozy＋一點荒謬，避免突然改成黑暗寫實。

揭示後立刻導向 **prestige（威望重開）** 入口，或與之同一畫面。

---

## 5. Prestige（威望／転生）

### 5.1 What resets / what stays

| 重置（典型） | 保留 |
|--------------|------|
| 當前 gold、庫存、本地圖進度 | **永久加成**：移動速度、貨廂容量、行情洞察（價格／趨勢提示） |
| 未完成的當前局任務狀態 | **敘事解鎖**：新外觀、記憶碎片 |

精確數值曲線 TBD；文件鎖定 **兩類獎勵都有**。

### 5.2 Narrative framing

- 重開 = 再丟進廢土／再當一次骰子；神可能還在看。
- 記憶碎片／外觀：每輪拼回「更像自己」或「更懂被換的那筆帳」——偏輕，不強制沉重。
- 行情洞察等加成用短 flavour 解釋（例：「這輪骰面比較記得漲跌」）。

### 5.3 Mirror on subsequent runs

Prestige 後再開場：**仍給鏡子**，風味改成「又來了」類知情／無奈幽默（非第一次驚嚇）。

### 5.4 When available

- **非常後期**（與 body-swap 完整揭示綁定或緊接其後）。
- 可重複 prestige；每輪疊加永久進度（diminishing returns TBD）。

## 7. Writing rules（文案規則）

1. 短。能一行 description 就不要三段。
2. 幽默落在用詞與反差（廢土＋溫馨日常），不要梗密度炸彈。
3. 中／英／日可混；日文適合術語與短概念標籤。
4. 不劇透結局在前中期系統說明裡。

---

## 8. Open questions（story）

1. 接近地圖終點的精確觸發站／任務？
2. ~~神稱謂~~ → **賽子／さいころ／Dice**；開場暗示與玩家有關
3. 記憶碎片要幾輪才能拼完？拼完有無「真結局」？
4. ~~Prestige 鏡子~~ → **仍給，文案「又來了」**
5. 選角外觀池有多大？威望解鎖外觀是否含「開場被換走的那套」？
